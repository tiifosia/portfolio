개인정보처리방침

방문자 정보

Team1 Portfolio(이하 "사이트")는 방문자의 개인정보를 수집하거나 저장하지 않습니다. 회원가입, 로그인, 입력 양식, 방문 분석용 쿠키가 없습니다.

작품 영상은 YouTube 플레이어(youtube-nocookie.com)로 재생되며, 재생할 때는 Google 개인정보처리방침이 적용됩니다.

YouTube API 사용

사이트의 작품 목록을 갱신하기 위해 YouTube Data API를 읽기 전용 권한(youtube.readonly)으로 사용합니다.

  • 운영팀 본인의 YouTube 채널(AI영상팀)의 업로드 목록에서 영상 ID, 공개 상태, 게시 시각만 읽습니다.
  • 읽은 정보는 사이트에 작품 카드를 추가하는 데에만 쓰며, 다른 목적으로 쓰거나 제3자에게 제공하지 않습니다.
  • 운영팀 외 다른 사용자의 Google 계정 정보에는 접근하지 않습니다.
  • Google API에서 받은 정보의 사용과 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한은 Google 계정의 서드 파티 연결에서 언제든 철회할 수 있습니다.
